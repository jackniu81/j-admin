## 依赖关系

```
#1 数据层基座
 ├── #2 认证与 RBAC ────┬── #4 前端登录与守卫 ── #5 后台布局 ── #6 表格页
 └── #3 业务接口 ───────┘
                                                        #7 Dashboard（依赖 #1 #2）
                                                        #8 通用能力（依赖 #4 #6，可并行收尾）
```

- `#1` 是一切前提：先有双数据源和统一响应，后面所有接口才有一致的形态
- `#4 #5` 可与 `#3` 并行（前端先用 mock 数据）
- `#7 #8` 不阻塞 P0 验收
